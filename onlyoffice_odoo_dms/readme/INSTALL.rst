This module requires:

* A running `ONLYOFFICE Docs <https://www.onlyoffice.com/download-docs.aspx>`_
  instance (self-hosted or cloud) reachable by both the Odoo server and client
  browsers. ONLYOFFICE Docs must also be able to POST callbacks back to Odoo.
* The `OCA DMS <https://github.com/OCA/dms>`_ module (``dms``).
* The ``onlyoffice_odoo`` base integration module.
